# Структура файлов данных

## users.txt

Файл содержит информацию о пользователях.

Поля:

- `userId` — ID пользователя.
- `name` — имя пользователя.
- `email` — адрес электронной почты.
- `gender` — пол.
- `date` — дата.
- `occupation` — профессия пользователя.

Разделитель полей: `|`

## tags.csv

Файл содержит пользовательские теги для фильмов.

Поля:

- `userId` — ID пользователя.
- `movieId` — ID фильма.
- `tag` — текст тега.
- `timestamp` — время добавления тега.

Разделитель полей: `,`

## ratings.csv

Файл содержит оценки пользователей фильмам.

Поля:

- `userId` — ID пользователя.
- `movieId` — ID фильма.
- `rating` — оценка фильма.
- `timestamp` — время выставления оценки.

Разделитель полей: `,`

## occupation.txt

Файл содержит список профессий.

Каждая профессия записана с новой строки.

## movies.csv

Файл содержит информацию о фильмах.

Поля:

- `movieId` — ID фильма.
- `title` — название фильма.
- `genres` — жанры фильма, разделённые символом `|`.

Разделитель полей: `,`

## genres.txt

Файл содержит список жанров фильмов.

Каждый жанр записан с новой строки.

## ratings_count.txt

Файл содержит две строки:
- ID пользователя и количество оценок для пользователя с минимальным ID;
- ID пользователя и количество оценок для пользователя с максимальным ID.

Разделитель полей: пробел.

## sqlite.txt

Файл содержит информацию о версии установленной СУБД SQLite и список доступных режимов вывода данных консольного клиента `sqlite3`.
