\# Task02



\## Требования к окружению



Для корректной работы скрипта необходимы:



\- Python 3;

\- SQLite 3;

\- Bash.



\## Запуск



Для создания базы данных необходимо запустить файл `db\_init.bat`.



Скрипт:



1\. запускает Python-утилиту `make\_db\_init.py`;

2\. генерирует SQL-скрипт `db\_init.sql`;

3\. выполняет SQL-скрипт с помощью SQLite;

4\. создаёт базу данных `movies\_rating.db`.



\## Структура базы данных



База данных содержит четыре таблицы:



\- `movies` — информация о фильмах;

\- `ratings` — оценки пользователей;

\- `tags` — пользовательские теги;

\- `users` — информация о пользователях.



После выполнения `db\_init.bat` должна быть создана заполненная база данных `movies\_rating.db`.
